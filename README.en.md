# vue3-basic

#### Description

Contains the basic configuration required for vue3 framework development products.

#### Software Architecture

vue3 + vite + ts + vue-router + pinia + element-plus + axios + scss

#### Instructions

1.  npm install
2.  npm run dev

#### Use Prompt

1.  If the node version is too early, it may fail to start (known versions 16.14.0 and later are available).
2.  npm download dependence is slow, or the download fails, you can try to switch Ali mirror (old Ali mirror address may be deprecated).
